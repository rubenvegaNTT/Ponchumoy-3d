# Ponchumoy 3D para iPad — v3 Arcade

Versión enfocada en jugabilidad: mucha más velocidad, aceleración rápida, cámara dinámica, tráfico, oleadas de obstáculos y pickups de turbo.

## Novedades v3

- Velocidad arcade: salida rápida, ~345 km/h a fondo y ~460 km/h con turbo.
- Aceleración y frenada mucho más reactivas.
- Turbo coleccionable de 4,5 s con efecto visual, sonido y aumento de FOV.
- Obstáculos generados por distancia y en oleadas de 1 a 3 carriles.
- Rivales con velocidad propia para que adelantarlos requiera conducción.
- Cámara más baja y dinámica para dar sensación de velocidad manteniendo visibilidad.
- Ajustes de rendimiento específicos para iPad (menor DPR y sombras dinámicas desactivadas en iPad).
- Service Worker v3 para forzar la actualización del juego instalado.

## Publicación

Descomprime el contenido directamente en la raíz del repositorio `Ponchumoy-3d`, reemplaza los archivos existentes, haz commit y push a `main`. GitHub Pages se volverá a desplegar automáticamente.
